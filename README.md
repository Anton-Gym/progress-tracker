# My Progress Tracker

A personal body stats and progress photo tracker. Works offline in any browser.

## How to use

Open `index.html` in any browser — no server or internet needed.

## How to put it on GitHub Pages (free, works on any device)

1. Go to [github.com](https://github.com) and create a free account if you don't have one.
2. Click **New repository** (the green button).
3. Name it `progress-tracker`, set it to **Public**, then click **Create repository**.
4. Click **uploading an existing file**, drag in `index.html`, then click **Commit changes**.
5. Go to **Settings → Pages** (left sidebar).
6. Under **Branch**, select `main` and click **Save**.
7. Wait about 60 seconds, then your app is live at:
   `https://YOUR-USERNAME.github.io/progress-tracker/`

Bookmark that URL and open it on any device.

## Notes

- Your data is saved in your browser's local storage — it stays on that device.
- Photos are stored as base64 in local storage; if storage fills up, delete older photo sets.
- Your June 8, 2026 baseline is pre-loaded and cannot be deleted.
- Log stats weekly. Photos every 4 weeks (weeks 1, 5, 9, 13…).
